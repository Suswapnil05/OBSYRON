1. **Brandes, U.** (2001). *A Faster Algorithm for Betweenness Centrality.* Journal of Mathematical Sociology, 25(2), 163-177.  
   *(Foundational algorithm used in `graph_engine.py` to identify critical lateral pivot entities across the attack graph).*
2. **Hagberg, A. A., Schult, D. A., & Swart, P. J.** (2008). *Exploring Network Structure, Dynamics, and Function using NetworkX.* In Proceedings of the 7th Python in Science Conference (SciPy2008), 11-15.
3. **Noel, S., & Jajodia, S.** (2004). *Managing Attack Graph Complexity Through Visual Hierarchies.* IEEE Transactions on Systems, Man, and Cybernetics, Part B, 34(4), 1627-1634.
4. **Wang, L., Islam, T., Kakavand, H., & Singhal, M.** (2008). *An Attack Graph-Based Probabilistic Metric for Network Vulnerability.* In Annual Computer Security Applications Conference (ACSAC), 283-292.
5. **Shannon, C. E.** (1948). *A Mathematical Theory of Communication.* Bell System Technical Journal, 27(3), 379-423.  
   *(Theoretical basis for Signal-to-Noise Ratio quantification in security telemetry reduction).*
